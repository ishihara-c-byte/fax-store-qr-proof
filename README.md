# FAX注文用紙 校正ツール

原稿Excelの「店舗情報」シートを、マスタ(FAXDMDB「住所TELFAX・その他」シート)と照合して、店舗情報とQRコードURLの誤りを一覧にします。

## ファイル
- `app.py` … 画面(Streamlit)
- `checker.py` … 照合ロジック
- `requirements.txt` … 必要なライブラリ

## 公開手順
1. GitHub のリポジトリに上の3ファイルをアップロード
2. https://share.streamlit.io で「New app」→ リポジトリを選び、Main file に `app.py` を指定して Deploy
3. マスタのスプレッドシートは共有設定を「リンクを知っている全員」が「閲覧者」にしておく

## チェック内容
| 項目 | 内容 |
|---|---|
| 正式店舗名・住所・住所２ | マスタと一致するか |
| 電話番号・FAX番号 | マスタと一致するか(ハイフン位置だけの違いは「低」) |
| DX・HC価格 | マスタと一致するか |
| 味噌汁・受付時間の文言 | マスタと一致するか(受付時間はマスタ空欄＝「前日21時までにご注文ください」) |
| QRコードURL | マスタと一致するか/URL形式が正しいか/原稿内「Web申込」シートのURLと一致するか |

マスタのセルに「→9/28配信～削除」などの変更メモがある場合は「中(要確認)」として出します。
